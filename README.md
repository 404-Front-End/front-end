# 🎬 CINEON+

### Sua próxima experiência de entretenimento começa aqui!

O **CINEON+** é um projeto de desenvolvimento front-end que apresenta a proposta de uma plataforma de streaming moderna, intuitiva e visualmente atrativa. A plataforma reúne diferentes categorias de entretenimento em um só lugar, proporcionando uma experiência de navegação simples e agradável.

---

## 🚀 Sobre o projeto

Desenvolvido como parte de um projeto acadêmico, o CINEON+ busca reproduzir a experiência de uma plataforma de streaming, com uma interface moderna, organização de conteúdos e navegação entre diferentes seções.

O projeto conta com páginas dedicadas a filmes, séries, esportes, transmissões ao vivo e muito mais.

## 🎨 Identidade visual

O CINEON+ apresenta uma identidade visual inspirada no universo do entretenimento digital, utilizando uma combinação de tons de azul e roxo para transmitir modernidade, tecnologia e inovação.

A interface foi pensada para oferecer uma experiência intuitiva, com elementos visuais que facilitam a navegação e a descoberta de novos conteúdos.

## 🛠️ Tecnologias utilizadas

As tecnologias utilizadas no desenvolvimento do projeto incluem:

- **HTML5** — estruturação das páginas.
- **CSS3** — estilização, layouts e identidade visual.
- **JavaScript** — interatividade e funcionalidades da interface.
- **Git e GitHub** — versionamento e colaboração no desenvolvimento.
